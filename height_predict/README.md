# Height Prediction App

A machine-learning application that estimates a person's height from selected demographic and physical characteristics. Built with Python and deployed using Streamlit.

## Features

- Predicts height using a trained machine-learning model.
- Accepts user characteristics as model inputs.
- Calculates BMI using the predicted height and entered weight.
- Provides an interactive web interface.

## Model

- **Algorithm:** Random Forest Regressor
- **Libraries:** Python, Pandas, Scikit-learn, Joblib and Streamlit

## Live Demo

[Try the Height Prediction App](https://heightpredictor-c5wwkypgorqnwfcmytrwdc.streamlit.app/)

## Limitations

This is an exploratory portfolio project intended for educational and demonstration purposes. Its predictions have not been established as reliable for medical or anthropometric use. Further validation against measured heights is needed.

## Deployment

The application is deployed using Streamlit.
